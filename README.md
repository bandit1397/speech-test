## 사용 순서

1. 두 폰 모두 app.html을 엽니다.
2. ⚙️ 설정에서 Gemini API 키를 입력합니다. 키는 저장되지 않으므로 페이지를 열 때마다 입력합니다.
3. Firebase에 로그인합니다. 두 폰 모두 같은 계정을 쓰고, 처음 한 번만 하면 브라우저에 유지됩니다.
4. 두 폰의 방 코드를 똑같이 맞춥니다.
5. 역할을 고릅니다. 경찰 폰은 👮 경찰 A, 외국인 폰은 🌍 외국인 B를 누릅니다. 외국인 폰에서는 언어 목록이 펼쳐지고, 외국인이 직접 언어를 고릅니다.
6. 🎤 버튼을 누르고 있는 동안 말하고, 떼면 전송됩니다. 짧게 톡 누르면 다시 누를 때까지 녹음합니다.

## 통역 절차와 원리 (Gemini 직접 모드, 기본값)

```
[말하는 폰]                                   [듣는 폰]
① 버튼 누름 → 녹음 시작
   (누르기 직전 약 0.25초도 함께 담음)
② 버튼 뗌 → 0.06초 더 녹음
③ 앞뒤 무음 제거 → 16kHz WAV → base64
④ Gemini에 1회 요청 (스트리밍)
   출력 1줄째 = 번역, 2줄째 = 받아쓰기
⑤ 번역 조각이 나올 때마다 Firebase에 씀 ──→ ⑥ 흐리게 표시 (작성 중)
   번역 줄이 끝나면 즉시 '완료'로 씀 ─────→ ⑦ 진하게 표시 + 진동 + 기록 추가
⑧ 받아쓰기는 내 화면 '내가 한 말'에만 표시
```

### 단계별 설명

1. **마이크 미리 열기:** 역할을 고를 때 마이크를 미리 켜 둡니다. 버튼을 누르기 전 약 0.25초 소리도 계속 보관해서(preroll) 첫 음절이 잘리지 않게 합니다.
2. **녹음:** 버튼을 누르고 있는 동안의 소리를 메모리에 모읍니다. 이때는 아직 아무것도 전송하지 않습니다.
3. **무음 제거:** 떼면 소리 크기를 보고 앞뒤 조용한 부분을 잘라냅니다. 앞 약 0.13초, 뒤 약 0.17초는 여유로 남깁니다. 업로드 크기와 음성 토큰이 줄어 응답이 빨라집니다.
4. **WAV 변환:** 16kHz 모노 16bit WAV로 바꾼 뒤 base64로 인코딩합니다.
5. **Gemini 요청 (말 한 번 = 요청 1회):**
   - 녹음을 Gemini에 보내 받아쓰기와 번역을 한 번에 처리합니다.
   - 번역을 1줄째에 먼저 출력하게 해서, 받아쓰기를 기다리지 않고 번역부터 받습니다.
   - 스트리밍(SSE)이라 단어가 나오는 대로 받습니다.
   - 설정: temperature 0, thinking 최소(minimal).
6. **Firebase 중계:**
   - 번역 조각을 `rooms/{방코드}/AtoB`(경찰→외국인) 또는 `BtoA`(외국인→경찰)에 씁니다.
   - 같은 발화는 같은 id로 덮어씁니다.
   - 번역 줄이 끝나는 순간 `done:true`로 써서 상대 화면을 확정합니다.
7. **상대 폰 표시:**
   - 상대 폰은 해당 경로를 실시간으로 구독하고 있습니다.
   - 작성 중일 때는 흐리게, 완료되면 진하게 표시하고 진동합니다.
8. **외국인 언어 공유:** 외국인 폰이 고른 언어를 `rooms/{방코드}/meta`에 씁니다. 경찰 폰은 이 값을 읽어 번역 방향을 자동으로 맞춥니다.

### 속도를 위한 장치

- **사전 연결:** 역할을 고를 때 0.5초 무음으로 Gemini에 1회 요청해서, 첫 요청이 느린 문제를 없앱니다. 버튼을 누를 때도 연결을 미리 열어 둡니다(이건 생성 요청이 아니라 한도를 쓰지 않음).
- **한도 초과 대처:** 3.1에서 429(한도 초과)가 나면 자동으로 3.5 Flash-Lite로 다시 요청합니다. 막힌 모델은 60초 동안 뒤로 미룹니다.
- **화면 꺼짐 방지:** Wake Lock으로 통역 중 화면이 꺼지지 않게 합니다.

### 측정값 보는 법 (화면 아래 6칸)

| 항목 | 뜻 |
|---|---|
| 번역 첫 조각 / 완료 | Gemini 요청 → 첫 번역 조각 / 번역 줄 완료까지 걸린 시간 |
| Firebase 전송 | 완료 번역을 Firebase에 쓰는 데 걸린 시간 |
| 전송 지연 (네트워크) | 상대 폰이 쓴 시각 → 내 폰이 받은 시각 |
| 수신: 첫 표시 / 완료 (말 끝→) | 상대가 버튼을 뗀 순간 → 내 화면에 처음 표시 / 완료 표시까지 (체감 속도) |
| 최종 인식 (뗀 후) | 크롬 음성인식 모드에서만 사용 |

### 크롬 음성인식 모드 (설정에서 선택, 예전 방식)

- 크롬 음성인식으로 받아쓴 글을 Gemini에 보내 번역합니다.
- 버튼을 떼는 즉시 그때까지 인식된 글로 번역을 시작합니다. 최종 인식 결과가 다르면 같은 id로 다시 번역해 덮어씁니다.
- 일부 폰에서 최종 인식이 3~16초 늦게 오는 문제가 있어 기본값은 Gemini 직접 모드입니다.

## 나중에 고칠 것

- **긴 발화에서 번역 누락:** 미란다 고지처럼 문장이 여러 개인 말에서 일부 문장이 빠질 때가 있습니다. 예를 들어 "변명할 수 있습니다", "체포적부심을 청구할 수 있습니다"가 빠지고 미국식 문구로 줄었습니다.
  - 원인:
    - 지시문의 "concise(간결하게)"
    - 미국식 미란다 문구로 끌려감
    - 번역을 받아쓰기보다 먼저 출력하는 구조
  - 해결 후보:
    - 지시문에서 concise를 빼고 "모든 문장 빠짐없이, 한 줄로" 지시
    - 경찰 용어집 추가
    - 미란다 고지 등 정해진 문장은 미리 번역해 둔 고지문 버튼으로 표시

## 무료 사용량 안내 (app.html, Gemini 무료 등급)

- 말 한 번 = Gemini 요청 1회 (녹음 → 받아쓰기+번역을 한 번에 처리). 페이지를 열고 역할을 고를 때 사전 연결 1회가 추가됩니다.
- Gemini 3.1 Flash-Lite 무료 한도: 분당 약 15회, 하루 약 500회 (외부 자료 기준, 변경될 수 있음)
  - 하루 약 490마디 (경찰+외국인 합계, 같은 키 기준)
  - 10분 대화(40~60마디) 기준 하루 약 8~12건
- Firebase: 무료 한도 안에서 사실상 무제한
- 한도를 늘리는 방법
  - 3.1 한도 소진(429) 시 자동으로 3.5 Flash-Lite로 재시도하고, 막힌 모델은 60초 동안 뒤로 미룸 (모델별로 한도가 따로 있음, 재시도 1회만큼 요청이 추가됨)
  - 두 폰에 서로 다른 Google 계정(프로젝트)의 키를 사용하면 한도 2배
  - 하루 한도는 한국 시간 오후 4~5시에 초기화
- 정확한 한도 확인: https://aistudio.google.com/rate-limit
- 주의: 무료 등급은 입력 내용(녹음 포함)이 Google 제품 개선에 쓰일 수 있습니다. 실제 사건 정보나 당사자 음성은 사용하지 말고 연습용 문장만 사용하세요.
