# speech-test

## 무료 사용량 안내 (app.html, Gemini 무료 등급)

- 말 한 번 = Gemini 요청 1회 (녹음 → 받아쓰기+번역을 한 번에 처리). 페이지를 열고 역할을 고를 때 사전 연결 1회가 추가됩니다.
- Gemini 3.1 Flash-Lite 무료 한도: 분당 약 15회, 하루 약 500회 (외부 자료 기준, 변경될 수 있음)
  - 하루 약 490마디 (경찰+외국인 합계, 같은 키 기준)
  - 10분 대화(40~60마디) 기준 하루 약 8~12건
- Firebase: 무료 한도 안에서 사실상 무제한
- 한도를 늘리는 방법
  - 3.1 한도 소진 시 설정에서 3.5 Flash-Lite로 변경 (모델별로 한도가 따로 있음)
  - 두 폰에 서로 다른 Google 계정(프로젝트)의 키를 사용하면 한도 2배
  - 하루 한도는 한국 시간 오후 4~5시에 초기화
- 정확한 한도 확인: https://aistudio.google.com/rate-limit
- 주의: 무료 등급은 입력 내용(녹음 포함)이 Google 제품 개선에 쓰일 수 있습니다. 실제 사건 정보나 당사자 음성은 사용하지 말고 연습용 문장만 사용하세요.

## 유료 사용 비용 안내 (app.html, Gemini 3.1 Flash-Lite 유료 단가 기준)

한 마디(5초 음성) 비용:

| 항목 | 토큰 | 비용 |
|---|---|---|
| 음성 입력 (초당 약 32토큰, $0.50/100만) | 약 160 | $0.00008 |
| 지시문 (텍스트 입력, $0.25/100만) | 약 120 | $0.00003 |
| 출력: 번역+받아쓰기 ($1.50/100만) | 약 50 | $0.000075 |
| 합계 | | 약 $0.00019 (약 0.26원) |

하루 10분 사용 시 (약 60마디):

| 기간 | 비용 |
|---|---|
| 하루 | 약 $0.011 (약 16원) |
| 한 달 (30일) | 약 $0.33 (약 470원) |
| $20로 사용 가능한 기간 | 약 1,800일 (약 5년) |

- 10분 내내 쉬지 않고 말하는 경우에도 하루 약 $0.02 수준입니다.
- 유료 등급은 입력 내용이 Google 제품 개선에 쓰이지 않습니다.
- 월 20달러 Google AI Pro(Gemini 앱 구독)에는 API 사용이 포함되지 않습니다. Gemini API는 AI Studio에서 프로젝트에 결제 계정을 연결하고, 사용한 만큼만 청구됩니다.
- 키 유출에 대비해 Google Cloud 콘솔 → 결제 → 예산 및 알림에서 월 예산 알림(예: $5)을 설정하세요.
- 단가는 변경될 수 있습니다: https://ai.google.dev/gemini-api/docs/pricing
